# Deploy to Oracle Cloud Always Free

A single bootstrap script turns a fresh Always Free VM into a running instance
with HTTPS, autostart, and the scheduler enabled. Everything else in this
folder is either generated by the script or used by systemd.

## 1. Create the VM (Oracle Console, ~10 min)

1. Sign up at <https://signup.cloud.oracle.com/> (they ask for a card to verify
   identity; you are NOT charged on the free tier).
2. Console -> Compute -> Instances -> **Create instance**.
   - Image: **Ubuntu 24.04** (pick from "Change image").
   - Shape: **Ampere (ARM) A1.Flex** — set **2 OCPU / 12 GB RAM**. This is the
     free allowance and it matters: the AMD `E2.1.Micro` shape has only 1 GB
     RAM and Playwright Chromium will OOM.
   - Add your **SSH key** (Generate on Windows: `ssh-keygen -t ed25519`, then
     paste the `.pub` content).
   - Create. Note the **Public IP**.
3. Open the ports: Networking -> Virtual cloud networks -> your VCN ->
   **Security Lists** -> Default Security List -> *Add Ingress Rules*:
   - TCP **22** (SSH), TCP **80**, TCP **443** — source `0.0.0.0/0`.

If you plan to use a domain (for automatic HTTPS), also point an **A record**
at the instance's Public IP at your DNS provider before running the script.

## 2. Get the script onto the server

From your local repo folder, push this commit, then on the server clone it:

```bash
# inside SSH:  ssh -i <your-key> ubuntu@<PUBLIC_IP>
sudo apt-get update -y && sudo apt-get install -y git
git clone https://github.com/sleepyrisu/job-hunter.git
```

(If the repo is private, use a Personal Access Token in the URL, or instead
copy your whole repo folder up with WinSCP and skip the clone.)

## 3. Run the bootstrap

```bash
cd job-hunter
sudo bash deploy/oracle/setup.sh              # HTTP on IP
# or with your domain (gets automatic HTTPS via Caddy):
sudo bash deploy/oracle/setup.sh jobs.my.com
```

Wait for it to finish (Playwright Chromium takes a few minutes). At the end it
prints the dashboard URL and token.

## 4. Add your API keys

```bash
sudo nano /opt/ai-job-hunter/.env     # fill in AGNES_API_KEY / GEMINI_API_KEY, email, etc.
sudo systemctl restart ai-job-hunter
```

Then open `http://<PUBLIC_IP>` (or your domain) and enter the printed
`DASHBOARD_TOKEN`.

## Useful commands

```bash
sudo systemctl status ai-job-hunter       # service status
sudo journalctl -u ai-job-hunter -f       # live logs
sudo journalctl -u ai-job-hunter --since today
sudo systemctl restart ai-job-hunter      # restart after .env edit
```

## How it fits together

- `/opt/ai-job-hunter` — the app (SQLite `jobs.db`, `settings.json` and
  generated cover letters live here, so they survive reboots).
- `ai-job-hunter.service` — systemd unit; starts `gunicorn --config
  gunicorn.conf.py app:app`. That config runs a single worker and starts the
  scheduler thread in the master process, so scheduled runs work under
  gunicorn too.
- Caddy — reverse proxy `80/443 -> 127.0.0.1:8888`, automatic HTTPS if a
  domain is supplied.
- UFW — only 22/80/443 open.

## Notes / caveats

- **Free tier limits**: 4 OCPU + 24 GB RAM total (Arm), 2 AMD VMs of 1 GB, up
  to 10 TB egress. One A1.Flex VM (2 OCPU/12 GB) is comfortably free.
- **Backups**: the VM disk persists, but make a snapshot of the boot volume if
  you care about `jobs.db`. (Oracle: Block Storage -> Boot Volume -> Backups.)
- **Security**: key-only SSH is already enforced; keep the instance's security
  list tight (only 22/80/443). For a bit more hardening, `sudo apt install
  fail2ban`.
